Implement dashboard endpoints per role, each as a small fixed number of aggregate SQL queries. Director: today's sessions (attended/cancelled), active clients, revenue today/week/month, pending payments, overdue reports, staff present, therapist utilisation, new leads, with a branch filter or All Branches. Therapist: total clients, today's schedule count, pending reports. Manager: operational view without P&L. Parent: total sessions and today's session for their children. Cache branch-level aggregates in Redis for 30 to 60 seconds keyed by branch and widget; never share per-user widgets (therapist, parent) through a shared key. Any list on a dashboard is limited to the top 10 with a link to the paginated endpoint. Add the indexes you need.
Done when: tests verify each role only receives the widgets and numbers it is allowed to see, cache expiry works, and query counts stay constant as data grows.
